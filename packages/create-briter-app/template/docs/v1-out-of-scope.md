# Intentionally Out of Scope in V1

- Multi-user auth and roles
- Teams, billing, or SaaS account models
- A database as the source of truth for posts
- Collaborative editing
- Rich-text or block-based editing
- A full media library manager
- Minute-precise scheduled publishing
- Cross-site adapter marketplace mechanics

These are left out on purpose so the first version can stay aligned with the
writer-first constraint instead of drifting toward a general-purpose CMS.
